# NOTE - in python a variable is a reference to a object in a memory so it means that everything is stored in memory as an object.
    
# MUTABLE VS IMMUTABLE   
- MUTABLE - mutable means we can change the object inside the memory without changing and reassign a new object in a memory.
    for example - list etc..

- IMMUTABLE - immutable means that we cannot change the same object inside memory instead we can change and store the value in a new object inside memory and then reassign the variable to that object.
    for example - string etc..
